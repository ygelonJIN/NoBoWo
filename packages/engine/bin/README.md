# Chiaki-ng 可执行文件放置目录

## 目录结构
```
bin/
├── mac/
│   └── chiaki          # macOS版本
├── win/
│   └── chiaki.exe      # Windows版本
└── linux/
    └── chiaki          # Linux版本
```

## 下载地址
https://git.sr.ht/~thestr4ng3r/chiaki/releases

## 安装步骤

### macOS
1. 下载 `Chiaki-ng-x.x.x-macos.dmg`
2. 打开dmg文件，将Chiaki.app复制到此目录
3. 或者将可执行文件从Chiaki.app/Contents/MacOS/chiaki复制到此目录

### Windows
1. 下载 `Chiaki-ng-x.x.x-windows.exe`
2. 将chiaki.exe复制到此目录

### Linux
1. 下载 `Chiaki-ng-x.x.x-linux.AppImage`
2. 将AppImage文件复制到此目录并重命名为chiaki
3. 添加执行权限：`chmod +x chiaki`

## 注意事项
- 确保Chiaki-ng版本与你的操作系统兼容
- 如果找不到可执行文件，NoBoWo会尝试使用系统安装的Chiaki-ng
